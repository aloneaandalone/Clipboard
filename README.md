# Clipboard Vibe

> 一个现代化的剪贴板历史管理器，让复制粘贴更高效。

## 它解决什么问题？

Windows 自带的剪贴板只能保存**最后一条**内容。当你需要在多个文本之间来回复制粘贴时，不得不反复切换窗口、反复按 Ctrl+C / Ctrl+V，效率很低。

Clipboard Vibe 会在后台自动记录所有复制过的文本，通过全局快捷键一键唤出，搜索、选择、粘贴一气呵成。

## 主要功能

- 📋 **剪贴板历史** — 自动捕获所有复制的文本，最多保存 200 条（可在 10~1000 之间调整）
- ⌨️ **全局快捷键** — 默认 `Ctrl+Shift+V` 唤出窗口，支持自定义任意组合
- 🔍 **实时搜索** — 输入关键词即时过滤，快速定位需要的内容
- ⭐ **收藏夹** — 标记常用内容，收藏项不会被自动清理
- 🎯 **键盘导航** — 纯键盘操作：`↑↓` 选择、`Enter` 粘贴、`Esc` 关闭、`Delete` 删除
- 🔔 **系统托盘** — 托盘图标常驻，右键菜单可快速清空历史或退出
- 🎨 **玻璃质感 UI** — 毛玻璃效果 + 深色主题，窗口跟随光标位置弹出
- 💾 **本地存储** — 数据保存在本地，不上传任何服务器

## 安装

### 环境要求

- Node.js >= 18
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 开发模式运行

```bash
npm run electron:dev
```

### 构建

```bash
npm run build
```

构建产物输出到 `dist/`（前端）和 `dist-electron/`（Electron 主进程）。

## 使用方法

### 1. 唤出窗口

按下全局快捷键 **`Ctrl + Shift + V`**，窗口会出现在光标附近。

> 💡 快捷键可以在「设置」中自定义。

### 2. 选择并粘贴

- 用 `↑` `↓` 方向键选择条目，按 `Enter` 直接粘贴到当前活动窗口
- 也可以用鼠标点击条目进行粘贴

### 3. 搜索

直接输入文字，列表会实时过滤匹配的剪贴板内容。

### 4. 收藏

鼠标悬停在条目上，点击 ⭐ 按钮将内容加入收藏。收藏的内容不会被自动清理。

### 5. 删除

- 选中条目后按 `Delete` 或 `Backspace` 删除单条
- 点击右上角 🗑️ 按钮清空全部历史（收藏项保留）

### 6. 设置

切换到「⚙️ 设置」标签页，可以：
- 修改全局快捷键
- 调整最大历史记录条数（10 ~ 1000）
- 恢复默认设置

## 输入输出示例

### 示例 1：多次复制后快速找回

**操作流程：**

```
1. 从网页复制 "Hello World"
2. 从文档复制 "const x = 42;"
3. 从终端复制 "npm install"
4. 按下 Ctrl+Shift+V 唤出窗口
5. 输入 "Hello" 搜索
6. 选中第一条，按 Enter
```

**剪贴板历史（按时间倒序）：**

| # | 内容预览 | 时间 |
|---|----------|------|
| 1 | `npm install` | 刚刚 |
| 2 | `const x = 42;` | 10 秒前 |
| 3 | `Hello World` | 30 秒前 |

**搜索 "Hello" 后：**

| # | 内容预览 | 时间 |
|---|----------|------|
| 1 | `Hello World` | 30 秒前 |

按 `Enter` → "Hello World" 被写回系统剪贴板并粘贴到当前光标位置。

### 示例 2：收藏常用代码片段

**操作：**

```
1. 复制一段常用的代码片段
2. 唤出窗口，点击 ⭐ 收藏
3. 切换到「收藏」标签查看所有收藏项
```

**效果：** 即使历史记录超过上限被自动清理，收藏的内容也会一直保留。

## 技术栈

- **Electron 31** — 桌面应用框架
- **React 18** — UI 框架
- **TypeScript** — 类型安全
- **Vite 5** — 构建工具

```
│   └── store.ts       # 剪贴板历史与设置的本地存储
├── src/               # React 前端
│   ├── App.tsx        # 主组件
│   ├── index.css      # 样式
│   └── main.tsx       # 入口
├── index.html
├── vite.config.ts
├── tsconfig.json
└── package.json
```
